# MQTT. Lives in base.txt because BOTH processes need it: the worker to ingest
# telemetry, the API to drive the broker's dynamic-security control topic.
#
# PINNED BELOW 3 ON PURPOSE. aiomqtt v3 is the only version exposing a manual
# `client.puback()`, and it is alpha and MQTTv5-ONLY — while protocol §1 freezes
# devices at MQTT 3.1.1 ("not MQTT 5 — the ESP32 firmwares must not need it").
# So on 2.x paho PUBACKs every QoS-1 message the instant it is handed over,
# BEFORE any database write. There is no ack to withhold and no redelivery, and
# worker/ingest.py is built around that rather than against it. Read its module
# docstring before moving this pin.
#
# paho-mqtt is aiomqtt's transport and is pinned explicitly rather than left to
# resolution: pytest runs under `filterwarnings = ["error::DeprecationWarning"]`,
# so a DeprecationWarning from either library at import or connect time fails the
# WHOLE suite, and an unpinned transitive is how that arrives without a diff.

paho-mqtt==2.1.0
